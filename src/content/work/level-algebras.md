Conjectures about these structures are easy to state and tedious to test by
hand, so I built a framework that verifies identities and searches for
counterexamples computationally. The mathematics itself uses category theory and
algebraic topology to characterise the structures; I'm contributing proofs to a
manuscript in preparation.
